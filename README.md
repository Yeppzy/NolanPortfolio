Open `index.html` in a browser.

- `index.html` — landing page, selected projects, upcoming, footer
- `works.html` — full works archive
- `about.html` — minimal about page
- `goals.html` — interactive goals board
- `contact.html` — contact page

- project pages such as `type-otf.html`, `flowriders.html`, `studio-flow.html`, `gaudi-100.html`, and `posters.html`
